    API Documentation

    Eze Ahuna
    //Universe Web API Calls
    ------------------------
    Calls can only be called
    On the Universe network.
    /**********************/

    (Guest Network Client List)
    Returns name, ip, and mac address
    of clients on the 'Guest' network.

    api link : (http://universe:850/info/client_list.php)

    - no paramters

    client names can sometimes return null or empty.

    ------------------------

    (Guest Network Client Stations)
    Returns the number of clients on the 'Guest' network.

    api link : (http://universe:850/info/clients.php)

    - no paramters

    the default number is 0

    ------------------------

    (Wake PC Request)
    Wakes a device or all wake on lan
    enabled devices on the Universe
    network. Returns true if the
    wake on lan request successfully was sent.

    api link : (http://universe:850//request/wake_pc.php)

    - mac : the mac address of the device to be woken.
    -ip : the ip address of the device to be woken,
    if both the ip & mac are supplied then the ip
    paramter will be ignored.

    if no paramters are supplied then every
    device on the network will be sent a request.

    Ex. (http://universe:850/request/wake_pc.php?mac=00:1a:a0:d12:55:7b)
